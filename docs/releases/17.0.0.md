# Slinker 17.0.0

## Added

- **Projects > Examples**: seven searchable built-in projects with source download,
  editable-copy opening and automatic Fit. Microsoft sign-in is not required.
- Original supplied **Flap - Winged Airer** and **Working Screen**, unchanged and
  hash-pinned, plus the earlier **Mechanism Playground** and three standalone
  details: crank-slider, damped carriage/end stop and torsion gripper.
- A new **spring-assisted two-stage scissor lift** with a moving platform rail,
  fixed floor slider, dashpot, two traces and an arm model-load sensor.
- An **examples/** source folder, generated public mirror, catalog with hashes,
  guide, release ZIP and individual model attachments.
- A prioritized **feature/patch backlog**, including the tutorial guide outline,
  Azure hardening, target-device qualification and engineering-model limitations.

## Safety And Verification

- Unsaved-project save/discard/cancel flow; validation before replacement;
  changed-session/signature and cancelled/late-fetch protection.
- Models are included before the normal build/worker generation, so the full
  library is precached for offline first opening rather than appended after build.
- CI now exercises the authorized original files with exact pins instead of
  silently skipping private-fixture coverage. Native gallery workflows test
  actual motion, original brown-handle Airer opening, Create restoration and
  downloaded save/reopen, alongside cumulative rebuild regressions.
- Coauthor credits remain **Jake Whiting and Hugo Wilson**. Original master/main
  and the preserved compatibility experiments are not replaced or force-pushed.

## Known Qualifications

Latest physical iPad/iPadOS/Safari/Home Screen/Pencil/VoiceOver testing is not
claimed from code/WebKit/touch emulation. Loads remain model units, with incomplete
slider/contact reactions. AZ-01/AZ-02 and wider live Microsoft account/hosted
interactive sign-in qualification remain open. Tutorial implementation is future
work, not part of this release. Legacy models retain and report old unresolved
barrier records rather than deleting their data.

See `docs/rebuild/evidence/v17/acceptance.md` for exact evidence and publication
outcome, `examples/README.md` for model use and provenance, and
`docs/rebuild/FEATURE-BACKLOG.md` for the next work.
