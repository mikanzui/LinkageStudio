# Session Handoff Template

Copy into the stage evidence folder; link the result from the progress tracker.

```text
Date / session:
Active gate / task / feature IDs / risk IDs / comparison rows:
Starting branch / commit / dirty state:
Lead/worker task IDs, base revisions and exclusive writable files:
Worker status: started / handed off / integrated / closed:
Expected behavior and independent reference:
Work completed and exact files changed:
Tests run and actual results:
UI workflow and numerical evidence:
Visual/usability comparison record:
Device qualification performed / still missing:
Failures, blockers and reproduction steps:
Decision changes with rationale:
Tracker/evidence documents updated:
Known-good commit / rollback artifact:
Elapsed time, integration/rework and reported usage (UNKNOWN when unavailable):
Parallel work worth retaining / reason:
Next task and exact first action:
```

Do not write 'fixed' or 'done' for behavior covered only by build/unit results.
