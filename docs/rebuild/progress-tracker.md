## Status Rules

`DONE` = stated task completed with evidence. `READY` = dependencies satisfied.
`TODO` = not started. `ACTIVE` = being worked. `BLOCKED` = a named dependency or
external condition prevents this task. `FAILED` = attempted acceptance did not pass.
Gate acceptance is recorded separately from task completion. No percentage is used.
`VERIFIED CHECKPOINT / TARGET OPEN` means the stated implementation tests passed,
but a named external qualification is still open; it is not a full target-app PASS.
